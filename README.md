One X post promoting make.fun's make-your-own-bounty launch. The post quotes make.fun's announcement from the @aegis_zhaoby account, carries a photo drawn for it (gen_photo.py makes post-photo.png), and this repository hands in the post's address in POST.json. The house scores the post's replies, reposts and quotes; the program here only copies POST.json to the output directory so the gate can read it.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
